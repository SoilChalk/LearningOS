## Core Capabilities (Directly Supported)

1. **Skill mastery estimation over time**  
   - BKT tracks how learner's mastery of a skill evolves across practice attempts ([Metricgate, source](https://metricgate.com/docs/sequential-irt-knowledge-tracing/))
   - Canonical model introduced by Corbett & Anderson (1995) for intelligent tutoring systems
   - Models student understanding as collection of knowledge components/skills

2. **Four-parameter model**  
   - Classic BKT uses four parameters per skill fitted from student performance data
   - Parameters relate performance to learning progression
   - Used in Cognitive Tutors for over 15 years

3. **Predictive capability**  
   - ITSs using BKT accurately predict student performance within system AND on external paper post-tests
   - Predicts latent student knowledge leading to successful post-test performance
   - "Hallmark of adaptive learning research and integral component of deployed intelligent tutoring systems"

4. **Contextual variants improve accuracy**  
   - Contextual estimation of student guessing and slipping improves prediction
   - Individual Difference Weights variant exists
   - Contextual-Guess-and-Slip variant developed

5. **Parameter space optimization**  
   - Study of 8,000+ students across four Cognitive Tutor courses shows parameter space can be reduced
   - Drastic reduction possible without compromising system behavior
   - Provides efficiency gains and assists interpretation

---

## Design Implications

1. **Skill-based learner modeling is validated**: BKT successfully models knowledge as decomposed skills/knowledge components

2. **Probabilistic approaches work**: Bayesian framework handles uncertainty in student knowledge estimation

3. **Transfer to external assessments**: System can predict performance outside tutoring environment - suggests knowledge model generalizes

4. **Context matters for accuracy**: Guessing and slipping parameters improve when contextualized

5. **Deployed at scale**: Used in Cognitive Tutors with thousands of students - demonstrates production readiness

6. **Efficiency-accuracy tradeoff exists**: Parameter reduction studies suggest models can be simplified

---

## Limitations and Non-Inferences

1. **Pedagogical action not specified**: BKT estimates knowledge state but doesn't prescribe teaching strategy

2. **Skill decomposition is manual**: "Generated by brainstorming and iterative refinement between subject experts, cognitive scientists and programmers"

3. **Parameter fitting requires data**: Four parameters per skill must be fitted using student performance data

4. **Skill granularity problem**: What constitutes a "knowledge component" is not algorithmically determined

5. **Model assumptions not detailed in snippets**: Bayesian network structure and transition assumptions not accessible here

6. **Original 1995 paper not accessed**: Relying on secondary sources and later work referencing BKT
